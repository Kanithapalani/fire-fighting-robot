# Fire Fighting Robot Using Wireless Sensor Network

## Project Description
This robot detects fire automatically using sensors and extinguishes it. It is controlled wirelessly using RF technology to avoid human risk in fire accidents.

## Components Used
- Arduino Uno
- Flame Sensor
- Temperature Sensor
- RF Transmitter & Receiver
- DC Motors & Motor Driver (L293D)
- Water Pump

## Working Principle
1. Flame sensor detects fire.
2. Signal sent via Wireless Sensor Network.
3. Robot moves towards fire location.
4. Water pump turns ON and extinguishes fire.

## Applications
- Used in factories, labs, and fire accident prone areas.
- Reduces human risk.
